## 🚀 Getting Started

### 1.  Setting up the Frontend
``` bash
cd client/client
npm install
npm run dev
```
Frontend will run at: http://localhost:5173

### 2. Setting up the Backend


```bash
cd client/backend
npm install
npm run start
```
Backend server will run at: http://localhost:8080
